# Birbal's Bakery 🍰

A modern and visually appealing **Bakery Website** built to showcase delicious cakes, pastries, and bakery services.  
Designed with a **pink pastel theme** and responsive layout, this website provides a user-friendly experience on both desktop and mobile devices.

---

## 🌟 Live Preview

Check out the live website here:  
https://bakery-website-liard.vercel.app/


---

## ✨ Features

- **Responsive Design**:
-  Works perfectly on desktops, tablets, and mobile devices.
- **Hero Section**:
-  Attractive banner with main text and CTA buttons.
- **About Section**:
-  Includes bakery story, images, and achievement stats.
- **Services Section**:
- Clear service cards with icons and descriptions.
- **Featured Products Section**:
- Highlighted cakes with “Add to Cart” buttons and sale tags.
- **Menu Section**:
-  Display of other bakery items in a grid layout.
- **Testimonials Section**:
- Happy clients feedback with profile pictures.
- **Contact Form**:
-  Simple and clean form for user inquiries.
- **Footer Section**:
- Social media links, contact info, and website navigation.
- **Smooth Hover Effects**:
- Buttons and cards animate slightly on hover.
- **Color Theme**:
- Elegant pink pastel colors with glowing highlights for hero & footer sections.

---

## 🎨 Color Theme

- **Hero & Footer**:
